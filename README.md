# KiwiAgents-Simulation
**Desarrollo de Sistemas Procedurales con Animaciones Cinemáticas en Unity**

Este proyecto tiene como objetivo desarrollar un sistema de control para bípedos en Unity, permitiendo que los agentes se desplacen de manera procedural en escenarios dinámicos. A lo largo de 4 meses, los alumnos trabajarán en la creación de mecánicas que permitan el movimiento de agentes de manera individual, en grupo, y en formaciones, integrando animaciones cinemáticas que mejoren la naturalidad de sus comportamientos. Este sistema puede evolucionar en etapas avanzadas para representar a personajes interactivos, como Kiwis, que interactúen con su entorno de manera compleja.

## Objetivos Generales
- Diseñar y programar sistemas de movimiento procedural en Unity para agentes bípedos.
- Implementar animaciones cinemáticas que complementen el sistema de navegación y comportamiento.
- Desarrollar escenarios interactivos en los que los agentes se muevan de manera autónoma, grupal y en formaciones.
- Introducir a los alumnos a conceptos avanzados como navegación con evasión de colisiones, formaciones dinámicas y comportamientos de enjambre.

## Objetivos Específicos
- Crear un bípedo base funcional con sistema de animaciones.
- Implementar comportamientos individuales como **Seek**, **Flee**, **Wander** y **Arrive**.
- Diseñar movimientos grupales con transiciones fluidas entre formaciones.
- Simular interacciones en entornos dinámicos, con obstáculos y otros agentes.
- Presentar un escenario integral donde los sistemas desarrollados se ejecuten en tiempo real.

## Alcance del Proyecto
El proyecto no busca desarrollar un videojuego completo, sino enfocarse en la creación de las mecánicas de control y comportamiento de agentes bípedos. Esto incluye su integración con sistemas de navegación y animación, así como la optimización para escenarios dinámicos y en tiempo real.

## Duración
4 meses, divididos en etapas mensuales con objetivos específicos y evaluaciones parciales.

## Equipo
El proyecto será desarrollado por **7 alumnos**, quienes asumirán roles específicos para cubrir las áreas de programación, diseño de escenarios y animación.
